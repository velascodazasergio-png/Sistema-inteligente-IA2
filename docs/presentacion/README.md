# Presentación final

Abre [`index.html`](index.html) en el navegador (doble clic). No necesita servidor ni conexión a internet.

- Navegación: flechas ←/→, barra espaciadora, Inicio/Fin, o los botones de la esquina.
- Cada diapositiva tiene su enlace (`index.html#5`).
- Para exportar a PDF: imprimir desde el navegador (cada diapositiva sale en una página).

Los datos provienen del [informe de análisis](../informe-analisis/README.md) y las capturas de [`docs/evidencias/frontend`](../evidencias/frontend).
